# 视觉项目验收清单

## 输入和环境

- [ ] 首次使用门禁结论及其证据已记录
- [ ] 已确认事实、用户选择、合理假设和待验证项已分开
- [ ] 系统、内核、架构和运行时版本已记录
- [ ] 摄像头设备、分辨率、像素格式和实际采集帧率已记录
- [ ] 光照、背景、目标距离/姿态和测试布置已记录
- [ ] 自动/锁定曝光、增益和白平衡策略及其实际值已记录
- [ ] 使用的 GPIO/UART/模型/标定数据来源已记录

## 算法和坐标

- [ ] 目标检测/测量/跟踪在固定输入上可重复
- [ ] 原图、中间结果、全部候选、拒绝原因和配置版本可追溯
- [ ] 坐标系、单位、方向、原点和标定方法已写明
- [ ] 无效检测、丢失、遮挡和重捕获状态已定义
- [ ] 动态 ROI 已有全帧基线，并验证边缘、扩大搜索和全帧重捕获
- [ ] 时序确认按实际频率/时间窗口定义，没有把固定帧数当作通用参数
- [ ] 误差计算与题目评分指标一致

## 接口和安全

- [ ] 通信帧、频率、超时和失败动作来自题目或用户确认
- [ ] 执行机构有初始状态、限幅、低速/空载测试和急停
- [ ] 观测带时间戳、有效性、质量和超时，过期观测不会继续驱动执行器
- [ ] PID/控制器已验证误差符号、采样时间、饱和/变化率限制和状态切换复位
- [ ] 激光、云台、电机、无人机等风险已隔离
- [ ] 未把下位机职责和 RK3566 职责混淆

## 性能和验收

- [ ] 采集 FPS、处理 FPS、发布频率和端到端延迟已分开记录
- [ ] 静态误差或动态误差达到题目要求，数据来自目标板
- [ ] 已记录误检/漏检、ROI 命中率、重捕获时间和安全停止时间
- [ ] 控制闭环已记录超调、稳态误差、抖动和饱和行为
- [ ] 完成必做项和所声明发挥项测试
- [ ] 已记录连续运行时间、异常次数和降级行为
- [ ] 待实测项目没有被写成已完成结论
- [ ] 每个合理假设都有影响说明、验证方法或已被实测替代

## 图传、部署与恢复（涉及时）

- [ ] 识别、预览和录像分辨率契约分别确认
- [ ] 编码、服务端队列、网络和播放器缓存已分层检查
- [ ] 慢客户端不会造成过期帧无界积压
- [ ] 用户指定的最终播放器/录像链路已实际验证
- [ ] 本地与板端活动文件、模型、配置版本及校验和一致
- [ ] 进程由明确 unit/PID 管理，不依赖宽泛进程匹配
- [ ] `service active`、真实帧、通信输出和端到端功能分别取证
- [ ] 候选部署失败时可回到已验证版本
- [ ] 自启、设备重连、网络切换失败和断电恢复按项目要求验证
