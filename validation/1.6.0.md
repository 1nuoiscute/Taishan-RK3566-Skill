## 4. 探针实板基线

没有在本次发布中执行泰山派实板探针。历史证据的边界继续见 [历史基线记录](hardware/2026-07-21-historical-baseline.md)。

v1.5.0 后的独立审查指出三个既有局限，本次仅扩展平台并保留探针源码，因此这些局限仍存在：

- UART 探针打开端口可能改变 RTS/DTR，即使没有发送数据也不能等同于无副作用；先枚举，设备与打开参数由用户确认。
- baseline 的 manifest 命令记录不完整，复现时还需额外保存实际调用命令。
- camera framesize 稳定性检查依赖打开时的尺寸，不能证明逐帧尺寸稳定。

这些项不能因 DSH 安装或合成测试通过而宣称已修复。当前脚本仍需在目标板复验。

## 5. 项目级端到端验证

本次端到端验证范围仅为 DSH 插件：安装包→Profile Bundle→真实模型技能调用→配套模板/资料读取→离线回答。不是 RK3566 摄像头、NPU、UART、网络或控制执行的端到端证明。

已在隔离 DSH_HOME 的 SDK Profile 安装实际 tgz；dump-config 确认 Bundle 行进入配置。实际已安装包通过原生 registry 资源与卸载检查。最终候选 53c6d34 已通过 GitHub 源码安装、资源逐字节比对和 Web Profile 卸载检查（无认证、未启动模型）。GitHub Actions 的 push/PR 两次完整门禁通过。安装包 41 个文件全部与源码逐字节一致。

发布附件包括 DSH tgz、Codex/Claude Code/DSH 目录 Skill ZIP 及 SHA256SUMS.txt。Desktop 终端安装入口由本机 2.0.17 文档确认，但 Desktop UI、桌面安装和其他预览版本未做运行验收。
